# SentinelX Getting Started Guide

Welcome to the **SentinelX Operational Orientation**. This guide details how to navigate the platform, boot up services, and interact with the primary dashboards.

---

## 1. Initial Access & Authentication
1. **Launch Portal**: Navigate to the main SentinelX console in your browser.
2. **Terminal Gateway**: You will be greeted by the **V4 Security Login Terminal**.
3. **Role & Tenant Provisioning**: 
   * Select your **Operator Role** (Administrator, Security Lead, Compliance Auditor, Risk Officer).
   * Choose your target **Active Tenant** partition (e.g., `CORE_GLOBAL_HQ`, `FINANCE_ZONE`).
   * Click **INITIALIZE SESSION**.

---

## 2. Navigating the Multi-Screen Experience
SentinelX is split into three main working domains:
* **The Main Landing Hub / Discovery Center**: The central portal presenting the system description, interactive architecture, capabilities index, and the competitive positioning overview.
* **The Battlespace / Digital Twin Simulator**: The active cyber warfare arena where you can launch attack vectors (Ransomware, DDoS, Zero-Days) and test network survival under stress.
* **The Enterprise Command Center**: The administrative glass pane monitoring the real-time enterprise operating system, tracking incident timelines, evaluating financial impacts, and manual triage.

---

## 3. Basic Exploration Workflow
1. **Search**: On the Command Center or EOS landing, enter a keyword like `payroll` to list any related application servers, developers, or databases.
2. **Inspect**: Hover over any server node to view its health status, line of business, and active connections.
3. **Analyze**: Open the **AI Intelligence Panel** to read model summaries of ongoing activities and advisories.
